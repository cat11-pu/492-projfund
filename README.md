# 492-projfund 资金分配推演台

纯静态页面，无需构建、无需服务器：**双击 `index.html` 即可运行**。

## 功能
- 载入 / 增删 / 改写项目条目：投入需求、资金池归属、优先级、前置与互斥关系（表格内直接编辑，支持 JSON 导入导出）。
- 约束传播推导每个项目是否可纳入分配及可用资金上限，每条结论附依据。
- 增量重判：每次调整只沿约束传播路径重判受影响项目，并自动与全量重推比对（页头 ✓ 徽标）。
- 前置环检测：环上项目明确判为不可纳入，顶部红色横幅列出环成员。
- 冲突保留：互斥或资金冲突双方均保留并各自给出冲突依据，不静默丢弃。
- 撤销：每次调整前快照状态与结论，撤销后结论与依据整体还原，无中间残留。

## 文件
- `index.html` — 页面与样式（入口）
- `engine.js` — 约束传播引擎（环检测 / 拓扑传播 / 互斥裁决 / 资金分配 / 增量闭包）
- `app.js` — 界面渲染、编辑交互、撤销历史
- `test-engine.js` — 引擎自测：`node test-engine.js`（含 2000 步随机变更下 增量==全量 校验）
